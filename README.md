# Parent Handbook HTML

Open `index.html` in a browser to view the web handbook.

Open `print.html` in a browser to print the handbook or save it as a PDF.

Keep the `img`, `assets`, and `colors_and_type.css` files in the same folder as the HTML files. The page needs those files for images and styling.

## Translations

Both pages include a **Translate** dropdown (top bar on `index.html`, floating bar on `print.html`) offering Spanish, Haitian Creole, and Swahili. Translation is powered by the free Google Translate website embed, so it requires an internet connection and works best when the pages are served from a website (translations are machine-generated). The dropdown is hidden automatically when printing.
